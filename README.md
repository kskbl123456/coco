# coco — WLoc 虚拟定位服务端

自研**服务端集中式** iOS 虚拟定位系统。手机连上 VPN 后，由服务端中间人改写 Apple WLoc
定位请求，使设备地图显示为指定坐标。

> 端侧客户端参考上游 `github.com/OpenHRTT/wloc`；**服务端实现为本仓库自有代码**。

---

## 架构

```
                        ┌─ 公网 origin ─────────────────────────────┐
                        │  登录 / 授权状态 / 下载描述文件            │
   iPhone               └───────────────────────────────────────────┘
     │
     │ IKEv2 VPN（UDP 500/4500）
     ▼
 ┌──────────────────────────────────────────────────────────────────┐
 │ strongSwan（leftid = 域名，隧道选择器 10.10.1.1/32）              │
 └──────────────────────────────────────────────────────────────────┘
     │
     ├─ 隧道 origin https://10.10.1.1:8443 ──────────────────────────┐
     │    设点 / 状态查询 / 地图 Key 下发（敏感接口只在这里暴露）      │
     │    ★「能访问到隧道地址」= 已连 VPN，无需额外鉴权层              │
     └───────────────────────────────────────────────────────────────┘
     │
     ├─ 路径 A：手动代理 10.10.1.1:9999 ──┐
     └─ 路径 B：DNS 直连 10.10.1.1:443 ───┤
                                          ▼
                              wloc_proxy.py（TLS MITM）
                                          │
                          改写 AppleWLoc 响应坐标 → gs-loc.apple.com
```

**关键设计**：敏感接口（设点、状态、地图 Key）只在**隧道内**暴露。
隧道流量选择器是 `10.10.1.1/32`，不连 VPN 根本路由不到那个地址 ——
**「能访问到隧道地址」本身就等于「已连 VPN」**，不需要额外鉴权层，
而且这些接口在公网上根本不存在（扫描器扫不到）。

## 关键协议要点

- 接口 `POST https://gs-loc.apple.com/clls/wloc`，**functionID 必须 = 1**
- 响应信封 `version(2) + 0000 + msgtype(2) + 0000 + len(u16BE) + payload`，
  **msgtype 会变（0001/0003），不可写死**
- **坐标是 varint 定点 `round(x × 1e8)`，不是 double**
- 改写对象：`f2` WifiDevice→内部 `f2` Location；`f22`/`f24` 基站实体→内部 `f5` Location
  （**两类 Location schema 不同**，只能替换子字段 1/2，不能照搬）
- 上游请求**必须带 `Accept-Encoding: identity`**，否则拿到 gzip 无法解析

## 主要功能

| 功能 | 说明 |
|---|---|
| 授权码登录 | 卡密 + 机器码绑定（首次登录即锁定设备） |
| 每用户独立 VPN 账号 | 一张卡密 → 一个 `wloc_<hex12>` → 独立隧道 IP → 独立坐标 |
| **隧道内 API** | 设点/状态/地图 Key 只走 VPN 隧道 |
| 高德 Key 服务端下发 | 不写在前端；支持多账号轮换（个人配额搜索仅 100/日） |
| 授权状态轮询 | 5 秒 + 3 个事件钩子 → 服务端可远程踢人 |
| 断 VPN 锁地图 | 遮罩禁用操作，**不销毁地图实例**（避免重下 SDK/瓦片） |
| 品牌动态下发 | 平台名/Logo/公告后台可改，不用发版 |
| 基站 + WiFi 双路径改写 | 真机验证通过 |

## 安全说明

本仓库**不含**任何凭据、私钥或用户数据。生产密钥位于服务器
`/etc/wloc-web/`、`/etc/ipsec.d/`，数据库 `wloc.db` 亦不入库。

⚠️ **面板要读的配置文件权限必须是 `root:wloc` + 640** —— 面板进程以 `wloc` 用户运行。
写成 `600 root:root` 会导致接口静默失败（`ok:false`，日志里不一定有报错）。
