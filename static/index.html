使用指南

1. 用 Safari 打开本页面，点击 “下载配置” 获取描述文件。

2. 到「设置」安装描述文件，然后在 设置 → 通用 → 关于本机 → 证书信任设置 中，开启根证书的完全信任。

3. 到 设置 → 通用 → VPN 与设备管理，连接 VPN。

4. 返回本页面点击 “进入系统”，在地图上点击或拖动图钉选定位置，点击 “锁定定位”。

5. 关闭再打开 设置 → 隐私与安全性 → 定位服务，定位即刻生效。

容易漏掉的两步：第 2 步的证书信任和第 5 步的开关定位服务。任一漏掉，定位都不会生效。
